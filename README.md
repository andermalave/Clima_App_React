☀️ App del Clima - Mi Primer Proyecto React
¡Hola! 👋 Esta es mi primera app en React, una práctica clave de mi curso para consolidar conceptos y la integración con APIs.

🚀 Tecnologías
React 19: La base de la UI.

JavaScript: Lógica principal.

Tailwind CSS: Estilizado rápido y responsivo.

Weather API: Consumo de datos meteorológicos.

✨ Características
🌍 Busca por Ciudad: Obtén el clima de cualquier ciudad.

🌡️ Datos Detallados: Temperatura (actual/máx), 💨 viento, 💧 humedad, y 📊 presión.

📝 Validación: Asegura que la ciudad sea ingresada y con la longitud correcta.

⚡ Async/Await: Peticiones a la API eficientes y no bloqueantes.

🔄 useState: Gestión del estado local de la app.

🛠️ Cómo Ejecutar
Clona: git clone https://github.com/tu-usuario/nombre-de-tu-repositorio.git

Accede: cd nombre-de-tu-repositorio

Instala: npm install (o yarn install)

Configura API: Crea .env con VITE_WEATHER_API_KEY=tu_clave_aqui

Inicia: npm run dev (o yarn dev) -> Abre en http://localhost:5173
